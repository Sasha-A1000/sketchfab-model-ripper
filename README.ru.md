# Sketchfab Public Downloader — Desktop (Windows 10/11)

**Версия desktop-приложения 1.0.0**

**Language / Язык:** [English](README.md) | **Русский**

Десктоп-версия основана на текущей ветке `main` расширения
[seryi882/sketchfab-downloader-extension](https://github.com/seryi882/sketchfab-downloader-extension)
(включая пайплайн ригов и анимаций; это не старый тег `v1.0`). **Тот же движок
и тот же дизайн**, но это обычное приложение для Windows: вставили ссылку →
справа собралось **3D-превью модели** → нажали «Скачать» → после сборки архива
открывается **окно Проводника с выбором, куда сохранить файл**, а затем
Проводник показывает готовый ZIP.

Публичные модели Sketchfab → **glTF (`.glb`) ZIP**. Без аккаунта, без логина,
без API-токена — статический ключ расшифровки берётся из живого вьюера
автоматически.

- 🧩 Пайплайн upstream main (меш, текстуры, дескрамбл, ORM, риги/анимации, массовая загрузка, dev-режим, EN/RU/ZH, светлая/тёмная тема)
- 🎮 **3D-превью сбоку** — как в ModHUB: без интерфейса сайта, только модель, которую можно крутить
- 📂 **Диалог сохранения в Проводнике** — выбираете папку и имя файла
- 🖥️ Один portable `.exe` для Windows x64 — без установщика

## Что нового по сравнению с расширением

| | Расширение (браузер) | Это приложение (Windows) |
|---|---|---|
| Где запускается | вкладка sketchfab.com | отдельное окно, сайт не нужен |
| Ссылка на модель | активная вкладка браузера | поле ввода / Ctrl+V / перетаскивание ярлыка |
| 3D-превью | — | панель справа: вращение, зум, панорама, каркас, сетка, авто-вращение, скриншот (ModHUB-style) |
| Сохранение | обычная загрузка браузера | **диалог Проводника** (после/до скачивания) + открытие папки с файлом |
| Массовая загрузка | отдельная вкладка расширения | вкладка «Массовая» + выбор папки, Проводник открывается в конце |
| Тексты/перехват WebGL | хуки страницы вьюера | не нужны: движок сам качает и дескраблит карты |
| Тяжёлые модели | offscreen-документ | отдельное скрытое окно-воркер (тот же смысл) |

Возможности основного пайплайна: полный архив или **только GLB**, размеры
текстур (Оригинал / ≤2K / ≤4K), дескрамбл PNG/JPEG (в т.ч. 4K/8K), упаковка
metal+roughness → **ORM**, скины/кости/анимации, `info.json`, `README.txt`,
`download-log.txt` в dev-режиме, три языка интерфейса и две темы.

## 3D-превью (фишка из ModHUB)

* Модель собирается **в фоне**, пока вы смотрите на список — панель справа,
  никакого интерфейса Sketchfab.
* **Два этапа:** сначала быстрый меш (обычно 1–3 с после расшифровки), затем
  автоматически подгружаются текстуры (до 1K на карту — превью остаётся лёгким).
  Бейдж в шапке панели показывает текущий этап.
* Управление: **ЛКМ — вращение**, **колесо — зум**, **ПКМ — панорама**.
* Кнопки: `Текстуры` (вкл/выкл загрузку карт в превью), `Пересобрать`,
  `Каркас`, `Сетка пола`, `Авто-вращение`, `Сброс камеры`, `Скриншот PNG`,
  `На весь экран` (Esc — выход).
* Анимации из GLB проигрываются автоматически (если они есть у модели).
* Превью читает готовый `.glb`, который отдаёт воркер, — то есть вы видите
  **ровно то, что попадёт в архив**.

## Сохранение: как работает диалог Проводника

Настройки → «Приложение Windows» → **Окно сохранения**:

| Режим | Поведение |
|---|---|
| **После скачивания** (по умолчанию) | Жмёте «Скачать» → движок полностью собирает ZIP → открывается **окно Проводника «Сохранить как»** → файл кладётся туда, куда вы указали → Проводник открывается уже на файле |
| Перед скачиванием | диалог открывается сразу при нажатии «Скачать» (как в браузере Chrome) |
| Без окна | файл молча сохраняется в последнюю использованную папку (папка «Загрузки» по умолчанию) |

Рядом — галочка **«Открывать Проводник на сохранённом файле»** (по умолчанию вкл).
Если закрыть диалог «Сохранить как», приложение спросит, сохранить ли уже
готовый архив в папку загрузок или удалить его.

## Запуск portable-сборки

Скачайте и запустите **`Sketchfab Public Downloader-portable-1.0.0-win32-x64.exe`**.
Это один portable-файл, установщика и мастера установки нет. При запуске
лаунчер может распаковывать файлы приложения во временную папку; настройки
сохраняются в `%APPDATA%\Sketchfab Public Downloader`.

> Файл не подписан код-сертификатом, поэтому SmartScreen может показать
> «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

При распространении `.exe` обязательно приложите ссылку на публичный исходный
репозиторий: <https://github.com/Sasha-A1000/sketchfab-portable-downloader>.

## Как скачать модель

1. Откройте приложение и вставьте ссылку на **публичную** модель
   (`https://sketchfab.com/3d-models/…`) — кнопкой «Вставить», Ctrl+V или
   перетащив ссылку из браузера. Ссылку можно передать и аргументом:
   `Sketchfab Public Downloader.exe "https://sketchfab.com/3d-models/…"`.
2. Справа сразу собирается 3D-превью; слева под ссылкой — карточка модели
   (автор, полигоны, лицензия, миниатюра).
3. При необходимости поправьте настройки: **Настройки → Скачивать текстуры** →
   **Применить настройки**.
4. Нажмите **«Скачать эту модель»**. Прогресс — полоска и лог.
5. По завершении выберите папку в окне Проводника — файл сохранится, и
   Проводник откроется на нём.

Импорт в Blender: **Файл → Импорт → glTF 2.0** → выберите `.glb`,
затем **Z → Предпросмотр материала** (в режиме Solid текстуры не видны).

## Настройки

| Настройка | По умолчанию | Когда действует |
|---|---|---|
| Скачивать текстуры (`sf_prefs.textures`) | Выкл | После **«Применить настройки»**; к имени ZIP добавляется `-textures`; карты встраиваются в GLB и отдельно сохраняются в режиме «Полный» |
| Режим разработчика (`sf_prefs.devMode`) | Выкл | После **«Применить настройки»**. Подробный лог + `download-log.txt` в архиве |
| Тема (`sf_prefs.theme`) | Светлая | Сразу |
| Язык (`sf_prefs.lang`) | Английский (EN / RU / ZH) | Сразу |
| Архив (`sf_prefs.packMode`) | Полный | Сразу. «Только GLB» оставляет `.glb`, `README.txt`, `info.json`; включённые текстуры остаются внутри GLB |
| Размер текстур (`sf_prefs.maxTextureEdge`) | Оригинал | Сразу. `0` = оригинал; `2048` / `4096` — максимум только при включённых текстурах |
| Окно сохранения (`desktop.saveMode`) | После скачивания | Сразу: `after`, `before` или `auto` (без окна, в последнюю папку) |
| Открывать Проводник (`desktop.openFolderAfterSave`) | Вкл | Сразу; действует при следующем сохранении |
| Строить превью автоматически (`desktop.previewAutoStart`) | Вкл | Сразу; управляет автосборкой после ввода ссылки |
| Текстуры в превью (`desktop.previewTextures`) | Вкл | Сразу; изменение перестраивает текущее превью (≤ 1K на карту) |
| Папка сохранения (`desktop.lastSaveDir`) / папка массовой загрузки (`desktop.bulkDir`) | Загрузки | Выбирается кнопкой; последняя папка сохранения запоминается |

Настройки хранятся в `%APPDATA%\Sketchfab Public Downloader\prefs.json`. Настройки движка имеют один источник истины — объект `sf_prefs`; параметры приложения Windows находятся в `desktop`. Старые плоские ключи `sf_*` и `desktop.askWhereToSave` мигрируют при запуске, включая явные значения `false`. Старый режим сохранения `none` преобразуется в `auto`.

## Массовая загрузка

Вкладка **«Массовая»**: вставьте список ссылок или UID (по одной на строку) →
выберите папку → «Скачать все». Модели качаются по очереди, у каждой —
статус в очереди; Проводник открывается в конце, когда всё готово.
Кнопка «Стоп после текущей» останавливает очередь.

## Разработка и сборка

Требования: **Node.js 22.12+** (Electron 44.8.0), npm и Windows 10/11 для
запуска приложения. Portable-цель electron-builder можно собирать на
поддерживаемой ОС.

```bash
npm install                  # установка зафиксированных зависимостей
npm test                     # mock-тесты настроек, миграции и описаний
npm start                    # запуск из исходников
npm run dist:portable        # Windows x64 portable EXE → dist/
```

`npm run dist` — псевдоним той же сборки; установщик не настраивается. В сборку
явно входят `app/**/*` и `icons/**/*`, в том числе `app/lib/wasm/decrypt.wasm`.

Флаги отладки:

```bash
npm start -- "https://sketchfab.com/3d-models/…"   # сразу открыть ссылку
npm start -- --tab=bulk                            # открыть вкладку «Массовая»
npm start -- --selftest="<url>"                    # самопроверка движка/превью
npm start -- --shot=shot.png --shot-delay=30000    # сохранить PNG окна и выйти
```

Иконки приложения и Windows EXE находятся в `icons/`.

### Структура проекта

```
app/
├── main/
│   ├── main.js          # окна, app:// и sfnet:// протоколы, диалоги, Проводник, очередь
│   ├── preload-ui.js    # мост окна UI (window.sf)
│   ├── preload-worker.js# мост окна-воркера (window.sfWorker)
│   └── store.js         # настройки (chrome.storage.local-совместимо)
├── shim.js              # объект chrome.* для движка + sfnet-прокси запросов
├── lib/                 # ⚠ движок на базе upstream main (GPL-3.0) + desktop-адаптации
│   ├── pipeline.js      # полный конвейер: вьюер → ключ → WASM → текстуры → GLB → ZIP
│   ├── sf-api.js, decrypt.js, descramble.js, orm.js, osgjs2gltf.js, zip.js …
│   └── wasm/decrypt.wasm
├── worker/worker.js     # скрытое окно: probe / preview (2 этапа) / download → файл
├── ui/
│   ├── index.html, ui.css, ui.js   # интерфейс (дизайн popup-а расширения + превью)
│   ├── preview.js       # панель 3D-превью (three.js: OrbitControls, GLTFLoader, RoomEnvironment)
│   └── diag.js          # сбор ошибок интерфейса
└── vendor/three/        # three.js r169 (MIT), локально, без CDN
```

Почему так: браузерное расширение делало тяжёлые операции в offscreen-документе
(4K-пакеты роняют service worker). Здесь ту же роль играет **скрытое окно-воркер**,
а главное окно остаётся лёгким и отзывчивым; сеть и файлы — в главном процессе.

### Отличия в реализации

* `app/lib/**` основан на текущей ветке `main` расширения, а не на старом теге
  `v1.0`. В desktop-версии добавлены строки интерфейса в `i18n.js`, а
  `packOrmMaps` экспортируется из `pipeline.js` для повторного использования
  при построении превью. Исходный JS отформатирован Prettier без намеренного
  изменения поведения.
* Запросы к `sketchfab.com` / `media.sketchfab.com` / `static.sketchfab.com`
  идут через внутренний протокол `sfnet://` (главный процесс добавляет
  Referer и заголовки CORS) — браузерные host-permissions в Electron недоступны.
* Перехват WebGL-текстур со страницы вьюера (хуки `viewer-inject.js`/`webgl-hook.js`)
  не используется: у приложения нет вкладки сайта. Обычные карты и так
  скачиваются и дескрамблятся ключом `pk`; для превью берутся карты ≤ 1K.
  Очень редкие «полосатые» карты, которые в расширении спасал blit вьюера,
  здесь могут остаться без декода — они и там попадали в `MISSING_BLIT.txt`.

## Если что-то не работает

1. Откройте **Настройки → Приложение Windows → «Логи и настройки» → «Открыть папку с логами»**
   (это `%APPDATA%\Sketchfab Public Downloader`).
2. В папке лежат `main.log` (запуск, ошибки, падения приложения) и `prefs.json` (настройки).
   Если приложение закрывается молча — лог всё равно останется, его можно прислать.
3. Включите **Настройки → «Режим разработчика» → «Применить настройки»** — тогда
   подробный лог конвейера появится на вкладке «Скачать» и в архиве
   (`download-log.txt`).
4. Частые причины: модель приватная/удалённая; нет доступа к sketchfab.com,
   media.sketchfab.com, static.sketchfab.com; нестандартный прокси/VPN.
